# True / False Bank — All Topics

> **How to use:** Cover the answer column. For each statement write "True" or "False" on paper, then check. In the 36th BMA paper, 10 T/F statements were worth 20 marks (2 marks each). Aim for 100% accuracy since these are factual checks.

| 10 | IPv6 addresses are 32 bits long. | **False** — IPv6 is 128 bits; IPv4 is 32 bits. |

| 12 | DNS uses UDP port 53 for standard queries. | **True** |

| 14 | Class A IP addresses have a default subnet mask of 255.0.0.0. | **True** |
